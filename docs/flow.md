# 执行顺序

从 [主技能](../.agents/skills/independent-review-workflow/SKILL.md) 开始，避免同时加载全部文档。

1. 读取原始要求和目标规则，保存原子任务合同；执行者 GPT-6 Sol/low 连续实现并自检；统筹 GPT-6.1 Sol/high 调度。
2. 记录原始证据，按 [启动策略](review-policy.md) 运行 decide。prepare 先补齐条件；self_check_only 明确未独立审核；stop 如实报告剩余项。
3. 需要审核时，冻结合同、相关源码、证据和分阶段阅读索引。先核对清单完整性，不把历史评价混入首读材料。
4. 首次/全新终审创建 fork_turns=none 的独立审核者；普通复验使用原审核者。只提供中性要求与路径，审核者自行取证、保存首次发现。
5. 审核者首次发现固定后再读历史结论，对照旧问题逐项复验；实现者自主修复，不要求审核者写补丁。
6. 重新冻结变化版本，按影响区/依赖/保留条件复验。默认最多三轮，不为分数循环。
7. 保存原始报告、取证登记、委派/工具记录与前后哈希。分别报告本轮、技术、全局状态和独立性限制。

同版本结论可复用须满足相同合同、相同冻结内容、当前范围适用且未发现污染；不因为只是“看起来小改”复用旧通过标记。完整字段见 [审核协议](review-protocol.md)，上下文失效处理见 [上下文协议](reviewer-context.md)。
